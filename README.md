# MulaSutras – Vedic Pattern Engine

Ancient mathematical algorithms from the Vedas, implemented in Python for modern computation.

## Sutras Implemented

| Sutra | Meaning | Script |
|-------|---------|--------|
| **Urdhva Tiryagbhyam** | Vertically and Crosswise | `urdhva_tiryagbhyam.py` |
| **Nikhilam Navatashcaramam Dashatah** | All from 9 and the last from 10 | `nikhilam.py` |
| **Vedic Multiply** | Intelligent Sutra Selection | `vedic_multiply.py` |
| **Shunyam Saamyasamuccaye** | When the sum is the same, that sum is zero | `shunyam.py` |
| **Ekadhikena Purvena** | By one more than the previous one | `ekadhikena.py` |
| **Parāvartya Yojayet** | Transpose and Apply | `paravartya.py` |
| **Vedic Pipeline** | Unified data processing | `vedic_pipeline.py` |

## Quick Start

```bash
python vedic_multiply.py 98 97    # intelligent multiplication
python ekadhikena.py square 65   # squaring by Ekadhikena
python paravartya.py 2 3 8 5 -1 3  # solve linear equations
python vedic_pipeline.py          # demo unified pipeline
